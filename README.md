## 🌐 Overview

StockVibe blends stock news scraping with real-time sentiment analysis, giving you an intuitive pulse of the market powered by NLP and concurrency.

It's fast. It's modular. It's got *vibe*.

---

## 🧠 Core Features

- 🔎 **Smart Scraping**  
  Parallelized, thread-based scraping across finance news sites.

- 💬 **Sentiment Analysis**  
  FinBERT-powered sentiment for each article. Know the mood.

- 🧰 **Modular Design**  
  Built with clean layers: fetch, parse, analyze, store, serve.

- 📊 **Streamlit UI?** : *(Probably)*  
  See sentiment trends, search stocks, visualize market emotion.
